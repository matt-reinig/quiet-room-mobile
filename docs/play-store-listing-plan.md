# Play Store Listing Plan

## Goal
Create the required Play Store store listing assets for the initial Quiet Room launch.

Primary focus:
- phone screenshots
- app icon
- feature graphic
- store metadata

using Android emulators instead of physical devices where needed.

---

# Overall Strategy

This effort should focus only on the assets required for initial Play Store submission.

Primary objective:
Ship a clean, trustworthy, review-ready first listing for Quiet Room.

This should NOT become:
- tablet optimization work
- Chromebook support work
- XR support work
- cinematic marketing production
- a large branding initiative

The current assumption is:
- phone screenshots are the only screenshot category required for initial submission
- tablet screenshots will not be included in the first launch attempt
- Chromebook/XR assets are not required

The plan below therefore focuses ONLY on:
- metadata
- required graphics
- phone screenshots

---

# Required Store Listing Assets

## Metadata
Required:
- App name
- Short description
- Full description
- Privacy policy URL
- Support email

---

## Graphics
Required:
- App icon (512x512)
- Feature graphic (1024x500)
- Phone screenshots (2–8)

---

## Explicitly Excluded From Initial Launch
Do NOT spend time on:
- 7-inch tablet screenshots
- 10-inch tablet screenshots
- Chromebook screenshots
- XR screenshots
- promotional videos

# Workstream 3 — Screenshot Quality Pass

## Step 1 — Curate Conversation Content

The conversation content matters heavily.

Need:
- meaningful responses
- concise exchanges
- emotionally grounded tone
- readable formatting
- visually balanced message lengths

Avoid:
- giant text walls
- emotionally distressed conversations
- AI hallucination energy
- confusing theological discussions
- anything implying therapy or sacramental authority

---

## Step 2 — UI Cleanup Before Capture

Before screenshots:
- remove debug banners
- remove loading states
- ensure stable layouts
- clean up spacing issues
- use realistic user content
- verify status bar appearance

Optional:
- dark mode if visually stronger

---

## Step 3 — Capture Screenshots

Capture the phone screenshots only for the initial pass.

No tablet screenshot work will be included in the initial launch effort.
