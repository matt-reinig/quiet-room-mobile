# Task 01 — Data Inventory Plan

## Goal
Create a single source of truth for all data collected, stored, and shared.

## Output
A table that drives:
- privacy policy
- store disclosures

## Table Shape
| Data Type | Collected | Stored | Shared | With Who | Purpose | Retention | Deletion |

## Steps
1. List all data types:
   - account info
   - chat messages
   - spiritual profile
   - metadata
   - logs
2. Identify storage (Firestore, logs, etc.)
3. Identify third-party sharing (AI provider)
4. Define retention (simple, honest)
5. Define deletion behavior

## Done When
- No guessing is required for store forms
- Policy can be written directly from this
